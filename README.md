# homebrew-tap

[Homebrew](https://brew.sh) formulas maintained by [@YunyueLi](https://github.com/YunyueLi).

## Install something from this tap

```bash
brew install YunyueLi/tap/<formula-name>
```

## Available formulas

| Formula | Description |
|---|---|
| [`clauderoam`](Formula/clauderoam.rb) | Your Claude Code config, anywhere. Across Macs. Across accounts. — [repo](https://github.com/YunyueLi/clauderoam) |

## Updating formulas

```bash
brew update
brew upgrade <formula-name>
```
